SMALL, ON PURPOSE

A place to practice level design.

Brushkeep is an independent, original learning project inspired by TrenchBroom’s brush-based editing. It is not affiliated with TrenchBroom and uses none of its code, artwork, or game assets.

This MVP edits axis-aligned cuboids and point markers, with an orbitable orthographic 3D preview and XY plan. It does not include CSG, vertex editing, texture imports, collision, playable previews, map compilation, or native TrenchBroom project import.

Scenes allow up to 400 objects within ±4,096 units. Undo stores 80 edits. Browser autosave is a convenience, not a backup. Export a Brushkeep JSON project for safekeeping.
